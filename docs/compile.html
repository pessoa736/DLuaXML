compile

dslx.compile

Compiles a .dslx file (or string) to Lua. The module is callable directly.

local compile = require("dslx.compile")

compile(config, chunkname?)

compile(config: table, chunkname?: string) → string | nil

Compiles DSLX code according to config. Returns the generated Lua string when tofile=false and run=false. Writes a .lua file when tofile=true. Executes inline when run=true. The optional chunkname is passed to load() for error messages.

Config fields

FieldDefaultDescription
input—Path to the .dslx file, or the source code string when asfile=false.
asfiletrueRead input as a file path. Set to false to pass code directly as a string.
tofiletrueWrite output to a .lua file. Set to false to return the generated code string instead.
runfalseExecute the result after generating it. When true, tofile is ignored.
output_nameinput nameOutput file name without extension. Defaults to the base name of input.
output_ext".lua"Output file extension.
output_dir"."Output directory for the compiled file.
relative_actual_filefalseResolve paths relative to the calling file instead of the current working directory.

Examples

Get generated Lua as a string

local compile = require("dslx.compile")

local code = compile({ input = "hello.dslx", tofile = false, run = false })
print(code)

Write output to a file

local compile = require("dslx.compile")

-- Compiles hello.dslx → out/hello.lua
compile({
    input      = "hello.dslx",
    output_dir = "out",
    tofile     = true,
})

Compile and run inline

local compile = require("dslx.compile")

-- No file written; code is generated and executed immediately
compile({ input = "hello.dslx", tofile = false, run = true })
