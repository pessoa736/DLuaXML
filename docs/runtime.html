runtime

dslx.runtime

Generates Lua source from an AST and optionally executes it.

local runtime = require("dslx.runtime")

SetHandler

runtime:SetHandler(name: string | string[], handler: fun)

Registers a custom code-generation handler for a node_type. name can be a single string or a table of strings to apply the same handler to multiple node types at once. The handler receives (node, handlers) and must return a Lua source string.

local runtime = require("dslx.runtime")

-- Custom handler for full elements
runtime:SetHandler("full_element", function(node, handlers)
    -- return a custom Lua code string for this node
    return node.element .. "()"
end)

-- Same handler for two node types
runtime:SetHandler({"full_element", "element_self_close"}, function(node, handlers)
    return node.element .. "{}"
end)

expr

runtime:expr(node: DSLX_AST_Node | string, handlers?: table) → string

Returns the generated Lua source for a single node. When node is a plain string it is quoted with string.format("%q"). The optional handlers table overrides specific node type handlers for this call only.

local src = runtime:expr(ast.children[1])
-- e.g. returns: 'div{name="div", props={}, childrens={}, node_type="element_self_close"}'

make_new_code

runtime:make_new_code(nodes: table, handlers?: table) → string

Generates the complete Lua source from a list of nodes — typically the children array of the root file node returned by the parser. The optional handlers table overrides specific node type handlers for this call.

local parser  = require("dslx.parser")
local runtime = require("dslx.runtime")

local ast = parser("local x = <div/>")
local src = runtime:make_new_code(ast.children)
print(src)
-- local x = div{name="div", props={}, childrens={}, node_type="element_self_close"}

runtime

runtime:runtime(file: DSLX_AST_Node, handlers?: table) → any

Generates Lua source and executes it via load(). Accepts the root file node (returned by the parser) or a plain list of nodes. If the last node is an element, it is automatically wrapped with return so the value is returned to the caller.

local parser  = require("dslx.parser")
local runtime = require("dslx.runtime")

local ast = parser([[
    local function div(el) return el.childrens[1] end
    <div>hello</div>
]])

local result = runtime:runtime(ast)
print(result)  -- hello

Built-in handlers

HandlerBehavior
luaReturns node.content as-is.
scriptReturns node.content (the raw expression).
stringReturns string.format("%q", str).
full_elementSerializes to name{name=…, props={…}, childrens={…}, node_type=…}.
element_self_closeSerializes to name{name=…, props={…}, childrens={}, node_type=…}.
propsSerializes the props table into a Lua table literal.
childrenSerializes the children list; skips whitespace-only newline entries.
fileCalls make_new_code on node.children.
