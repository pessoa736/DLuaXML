import

dslx.import

Integrates DSLX into Lua's require() system. Called automatically by require("dslx").

local import = require("dslx.import")

When you call require("dslx"), the import module installs the .dslx searcher into package.searchers automatically — you don't need to call install() yourself in the common case.

install

import.install(pos?: integer, opts?: table) → import

Inserts the DSLX searcher into package.searchers at position pos (default: 2). Safe to call multiple times — it won't insert duplicates. Returns import for chaining.

local import = require("dslx.import")
import.install()         -- insert at position 2 (default)
import.install(3)        -- insert at position 3

uninstall

import.uninstall(opts?: table) → import

Removes the DSLX searcher from package.searchers. After calling this, require() will no longer find .dslx files. Returns import for chaining.

import.uninstall()  -- remove from require()

loadfile

import.loadfile(filename: string, opts?: table) → chunk | nil, err

Reads, compiles, and returns a loadable chunk from a .dslx file. Respects the cache: if the file hasn't changed since the last load, the cached chunk is returned. On failure returns nil and an error string.

local chunk, err = import.loadfile("mymodule.dslx")
if chunk then
    chunk()
else
    print("error:", err)
end

reload

import.reload(name: string, opts?: table) → result, err

Clears package.loaded[name] and reloads the module from disk, bypassing the cache. Useful during development when you want to pick up changes without restarting the Lua process.

import.reload("mymodule")  -- reloads mymodule.dslx from disk

clear

import.clear(opts?: table)

Clears all loaded .dslx modules from package.loaded and wipes the compilation cache. After calling this, all .dslx modules will be recompiled on next require().

import.clear()  -- wipe all cached .dslx modules

syncPath

import.syncPath()

Rebuilds import.path from the current package.path. Call this after modifying package.path at runtime to ensure the DSLX searcher picks up the new search paths.

package.path = package.path .. ";./components/?.dslx"
import.syncPath()  -- refresh import.path from updated package.path

Properties

import.path
The package.path-style string used by the searcher for .dslx files. Rebuilt from package.path on install and via syncPath().
import.use_cache
boolean (default: true). Caches compiled chunks — a file is only recompiled when its source changes on disk.
import.show_debug
boolean (default: false). Prints debug info about searcher installs, file loads, and cache state to stdout.

Full example

-- main.lua

-- Add .dslx files to the search path
package.path = package.path .. ";./src/?.dslx"

-- require("dslx") installs the searcher automatically
local dslx = require("dslx")

-- Load a .dslx module transparently via require()
local ok = require("mymodule")  -- loads src/mymodule.dslx

-- Reload from disk (bypasses cache)
dslx.import.reload("mymodule")

-- Wipe all cached .dslx modules
dslx.import.clear()

-- Remove the .dslx searcher from require()
dslx.import.uninstall()

-- After modifying package.path, sync the import searcher
package.path = package.path .. ";./extra/?.dslx"
dslx.import.syncPath()
dslx.import.install()  -- re-install if previously uninstalled
