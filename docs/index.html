Ways to use

In a .dslx file, any Lua function can be called as a tag. The tag becomes a call that receives one table: { name, props, childrens }. Everything compiles to plain Lua before it runs.

01

Components with require

Write components in a .dslx file and load it like any Lua module. require("dslx") installs a searcher for .dslx files. Nested tags run first, and what they return becomes the parent's childrens. 

-- list.dslx
local function item(el)
    return "- " .. table.concat(el.childrens)
end

local function list(el)
    return el.props.title .. "\n" .. table.concat(el.childrens, "\n")
end

return <list title="Groceries">
    <item>milk</item>
    <item>{2 + 1} apples</item>
</list>
-- main.lua
package.path = package.path .. ";./?.dslx"
require("dslx")
print((require("list")))
--> Groceries
--> - milk
--> - 3 apples
02

Compile ahead of time

Turn a .dslx file into a plain .lua file, so the code that ships doesn't need DSLX at runtime. 

local compile = require("dslx.compile")

-- writes ./hello.lua
compile({ input = "hello.dslx" })

-- or compile and run it right away
compile({ input = "hello.dslx", run = true })
03

Compile a string

Pass code instead of a file name and get the generated Lua back, to see exactly what a tag turns into. 

local compile = require("dslx.compile")

local code = compile({
    input  = '<print a="x">{1 + 1}</print>',
    asfile = false,
    tofile = false,
})
print(code)
--> print{name="print", props={a="x"}, childrens={1 + 1}, node_type="full_element"}
04

Parser and runtime

Go one level down: parse code into an AST, generate Lua from it, or register your own handler for a node type to change what gets generated. 

local dslx = require("dslx")

local ast = dslx.parser("local x = 1\n<box size={3}/>")
print(ast.node_type)                 --> file
print(ast.children[2].node_type)     --> element_self_close

print(dslx.runtime:make_new_code(ast.children))
--> local x = 1
--> box{name="box", props={size=3}, childrens={}, ...}

dslx.runtime:SetHandler("element_self_close", function(node, handlers)
    return --[[ your own Lua code for this node ]]
end)
