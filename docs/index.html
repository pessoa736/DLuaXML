DSLX

Davi System: Lua XML

Write Lua functions as XML tags. Every .dslx file becomes plain Lua before it runs.

Read the documentation
luarocks install daviluaxml

Needs Lua 5.5. The project is experimental, so the API can still change.

Ways to use it

A tag is a function call. <item>milk</item> calls item with one table: its name, its props and its childrens.

Write components and require them

Load a .dslx file like any Lua module. Inner tags run first, and what they return becomes the outer tag's childrens.

-- list.dslx
local function item(el)
    return "- " .. table.concat(el.childrens)
end

local function list(el)
    return el.props.title .. "\n" .. table.concat(el.childrens, "\n")
end

return <list title="Groceries">
    <item>milk</item>
    <item>{2 + 1} apples</item>
</list>
-- main.lua
package.path = package.path .. ";./?.dslx"
require("dslx")
print((require("list")))
--> Groceries
--> - milk
--> - 3 apples

Compile to plain Lua

Turn a .dslx file into a .lua file ahead of time, so what you ship doesn't need DSLX at all.

local compile = require("dslx.compile")

-- writes ./hello.lua
compile({ input = "hello.dslx" })

-- or compile and run it in one go
compile({ input = "hello.dslx", run = true })

See what a tag becomes

Compile a string instead of a file and get the generated Lua back.

local compile = require("dslx.compile")

print(compile({
    input  = '<print a="x">{1 + 1}</print>',
    asfile = false,
    tofile = false,
}))
--> print{name="print", props={a="x"}, childrens={1 + 1}, node_type="full_element"}

Change how code is generated

Parse code into a tree, generate Lua from it, or register your own handler for a kind of node.

local dslx = require("dslx")

local ast = dslx.parser("local x = 1\n<box size={3}/>")
print(ast.children[2].node_type)   --> element_self_close

print(dslx.runtime:make_new_code(ast.children))
--> local x = 1
--> box{name="box", props={size=3}, childrens={}, ...}

dslx.runtime:SetHandler("element_self_close", function(node, handlers)
    return --[[ the Lua code you want for this node ]]
end)

Every option of these modules is in the documentation, and the playground compiles DSLX in your browser.
