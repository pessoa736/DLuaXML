parser

dslx.parser

Parses DSLX code into an AST using LPeg. The module is callable directly.

local parser = require("dslx.parser")

parser(code)

parser(code: string) → DSLX_AST_Node

Parses code and returns the root AST node ({node_type="file", children={...}}). On failure, returns a table whose tostring is "nil (Falha no Parser)".

local parser = require("dslx.parser")

local file = parser("local x = <div/>")
-- file.node_type == "file"
-- file.children  == list of nodes

Node types

node_typeDescription
fileRoot node. children holds all top-level nodes.
luaRaw Lua code segment. content holds the source string.
scriptA {expr} block. content is the expression.
full_elementA <tag>...</tag> element.
element_self_closeA <tag/> element.
element_propProps table node (inside an element).

Parser properties

parser.patterns
Table of all registered LPeg patterns, keyed by name.
parser.lpeg
The LPeg module, pre-imported and available for building new patterns.
parser.parser_principal
Name of the pattern used as the entry point. Default: "File_parser".

SetPattern

parser:SetPattern(name: string, pattern: lpeg_C_object)

Registers (or replaces) a pattern under name. The pattern must be a captured LPeg object (lpeg.C(...) or equivalent).

local parser = require("dslx.parser")
local lpeg   = parser.lpeg

-- Register a custom pattern that matches a bare identifier
parser:SetPattern("my_ident", lpeg.C(lpeg.R("az","AZ")^1))

GetPattern

parser:GetPattern(name: string) → lpeg_C_object

Returns the registered pattern for name. Throws an error if the pattern doesn't exist.

local base = parser:GetPattern("File_parser")

SetParserPrincipal

parser:SetParserPrincipal(name: string)

Sets which pattern :match() and the callable form parser(code) use as the entry point. name must already be registered via :SetPattern().

parser:SetParserPrincipal("File_parser_strict")

match

parser:match(code: string) → any?

Runs the current principal pattern against code. Returns the raw LPeg match result without any metatable wrapping. Useful when you've set a custom principal pattern.

local raw = parser:match("<div/>")

Extending the parser

Use the pattern API to compose new entry points on top of existing ones. The example below creates a strict parser that fails if there is any leftover input after the last node:

local parser = require("dslx.parser")

parser:SetPattern("File_parser_strict",
    parser:GetPattern("File_parser") * -parser.lpeg.P(1))

parser:SetParserPrincipal("File_parser_strict")

local file = parser("<div/>")  -- uses the strict pattern

Pattern composition is static: changing a base pattern (e.g. element_name) after load does not affect patterns already composed with it. Extend by composing on top of existing named patterns, as shown above.
